# 🛡️ Release Governance Policy
1. **Length**: Commit messages must be at least 10 characters long.
2. **Professionalism**: No profanity or vague terms like "wip", "stuff", or "misc".
3. **Traceability**: The message MUST contain a Ticket ID (e.g., "JIRA-123") OR be a merge/setup commit.
4. **Friday Rule**: If today is Friday, the release is blocked unless the message contains "URGENT".
