# 🛡️ Release Governance Policy

1. **Length**: Commit messages must be at least 15 characters long to ensure clarity.
2. **Professionalism**: No profanity, slang, or vague terms like "wip" or "stuff".
3. **Traceability**: The message MUST contain a Ticket ID (e.g., "JIRA-123", "ISSUE-456", or "#12").
4. **Friday Rule**: If today is Friday, the release is blocked unless the message contains some text like URGENT-FIX".
